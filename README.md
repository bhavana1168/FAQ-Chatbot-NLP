# 🤖 FAQ Chatbot

An NLP-based FAQ Chatbot built using Python, Flask, NLTK, and Scikit-learn. The chatbot processes user queries and returns the most relevant answer using TF-IDF Vectorization and Cosine Similarity.

## 🚀 Features

* FAQ Question Answering
* NLP Text Preprocessing
* TF-IDF Vectorization
* Cosine Similarity Matching
* Interactive Web Interface

## 🛠️ Technologies Used

* Python
* Flask
* NLTK
* Scikit-learn
* HTML, CSS, JavaScript

## 🔗 Repository
https://github.com/bhavana1168/FAQ-Chatbot-NLP.git


## ▶️ Run the Project

```bash
pip install flask nltk scikit-learn
python app.py
```

Open in your browser:

```text
http://127.0.0.1:5000/
```
